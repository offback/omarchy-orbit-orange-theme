# Orbit Orange

A dark Omarchy theme built from 1970 Pontiac GTO in Orbit Orange.

![preview](preview.png)

## What it is

Pontiac's Orbit Orange was a 1970 one-year colour, best known on the GTO Judge. Warm orange on burnt umber, with the bright ANSI slots pushed toward amber — a dusk-in-August desktop.

## Install

```bash
omarchy theme install https://github.com/offback/omarchy-orbit-orange-theme.git
# or, from a local clone:
cp -r omarchy-orbit-orange-theme ~/.config/omarchy/themes/
omarchy theme set orbit-orange
```
